# OSS Nix pilot implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in, OSS-only Nix flake that pins command-line tools and exposes a reproducible development shell without changing the current Stow/Homebrew/Work installation path.

**Architecture:** A root `flake.nix` will expose a default shell for `aarch64-darwin` and `x86_64-darwin`, using a locked stable `nixpkgs` input. A shell test will evaluate the flake and inspect commands only inside `nix develop`; it will never activate Home Manager, nix-darwin, Stow, Homebrew, or system settings.

**Tech Stack:** Nix flakes, Nixpkgs, POSIX shell tests, Markdown documentation.

**Spec:** `docs/superpowers/specs/2026-08-27-oss-nix-pilot-design.md`

## Global Constraints

- Change only the public OSS checkout.
- Do not modify `bootstrap.sh`, numbered installers, `Brewfile`, Stow packages, live `$HOME`, or the Work checkout.
- Do not install Nix or any package as part of the repository change.
- Do not put secrets or mutable application state in Nix expressions or the Nix store.
- Preserve the existing untracked `docs/2026-08-27-macos-bootstrap-tooling-audit.md` file.
- The existing current-branch commit `f38af5a` is the design-spec baseline; the sandbox prevented feature-branch creation.

### Task 1: Add the pinned OSS flake

**Files:**
- Create: `flake.nix`
- Create: `flake.lock` (generated by Nix from `flake.nix`)

**Interfaces:**
- Produces `devShells.aarch64-darwin.default` and `devShells.x86_64-darwin.default`.
- Produces `checks.<system>.default` that evaluates the same shell package set.
- Does not produce activation modules, home-manager configurations, or system mutations.

- [ ] **Step 1: Define the failing prerequisite check**

Run:

```bash
if command -v nix >/dev/null 2>&1; then
  nix flake check
else
  test ! -e flake.nix
fi
```

Expected: the check exits 0 because Nix is not installed and the flake does not exist yet. This records the current prerequisite without invoking an installer.

- [ ] **Step 2: Write the minimal flake**

Create `flake.nix` with a single `nixpkgs` input and explicit systems `aarch64-darwin` and `x86_64-darwin`. Define one shared package list containing `bat`, `curl`, `eza`, `fd`, `fzf`, `git`, `git-delta`, `jq`, `neovim`, `nodejs`, `python3`, `ripgrep`, `rustc`, `cargo`, `starship`, `stow`, `tree-sitter`, `uv`, `wget`, `yazi`, `zellij`, and `zoxide`. Expose that list through `devShells.<system>.default` using `pkgs.mkShell` and add a shell check that evaluates the shell derivation.

- [ ] **Step 3: Generate the lockfile**

Run:

```bash
nix flake lock
```

Expected: Nix writes `flake.lock` with the exact resolved `nixpkgs` revision. If Nix is unavailable, record the command as blocked and do not hand-write lock data.

- [ ] **Step 4: Verify evaluation**

Run:

```bash
nix flake check
```

Expected: exit 0 with no activation, package installation, or home-directory changes.

- [ ] **Step 5: Commit the flake slice**

```bash
git add flake.nix flake.lock
git commit -m "feat: add OSS Nix development flake"
```

### Task 2: Add the opt-in validation command

**Files:**
- Create: `tests/nix-pilot.sh`

**Interfaces:**
- Exit 0 after evaluating the flake and checking the expected commands inside `nix develop`.
- Exit 77 with a human-readable prerequisite message when `nix` is absent.
- Never invoke `nix profile install`, `darwin-rebuild`, `home-manager`, `sudo`, `brew`, or `stow`.

- [ ] **Step 1: Write the failing test**

Create the test with `set -euo pipefail`. If `nix` is absent, print `SKIP: Nix is not installed; install it manually before running the OSS pilot` and exit 77. If present, run `nix flake check` and then `nix develop --command bash -lc 'command -v ...'` for every command in the flake package set.

- [ ] **Step 2: Run the test**

Run:

```bash

```

Expected on this machine: exit 77 with the prerequisite message because `nix` is not installed. Any other exit is a test defect to fix before continuing.

- [ ] **Step 3: Re-run after Task 1**

Run the same command. Expected: exit 0 when Nix is available; otherwise the same explicit exit 77 prerequisite result.

- [ ] **Step 4: Commit the test**

```bash
git add tests/nix-pilot.sh
git commit -m "test: validate OSS Nix pilot shell"
```
